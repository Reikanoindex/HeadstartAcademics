# Headstart Academics website

This is a simple multi-page static website for GitHub Pages.

## Pages

- `index.html` — Home
- `courses.html` — Courses
- `history.html` — History
- `photos.html` — Photo gallery
- `forms.html` — Course enquiry form

## Publish on GitHub Pages

1. Create a new public GitHub repository.
2. Upload every file and folder from this package without changing the folder structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Replace gallery placeholders

Replace the six SVG files in `assets/photos/` with your own images. For the easiest replacement, export your photos as SVG with the same names or change the image paths in `photos.html` to `.jpg` or `.png` filenames.

## Important form note

Because GitHub Pages is a static host, the enquiry form opens the visitor's email app and prepares a message to `kanya@headstartacademics.com`. It does not store form entries in a database.
